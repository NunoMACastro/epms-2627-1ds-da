# Laboratórios

- [Primeiras páginas](frontend/primeiras-paginas/README.md): imagem provisória para o laboratório de HTML e semântica, para quem ainda não tem uma imagem do tema do seu site.
- [Formulário local](frontend/formulario-local/README.md): pequena aplicação para o browser, com um formulário e uma lista de tarefas, que serve de ponto de partida ao laboratório do bloco de formulários.
- [Conflito em Git](git/conflito-controlado/README.md): script que mostra, num repositório de treino, como aparece e como se resolve um conflito entre dois ramos, para o laboratório do bloco de colaboração e conflitos.
