# Formulário local: material de apoio

Material de apoio a um laboratório futuro, do bloco Formulários, validação e módulos.

Esta pasta tem uma pequena aplicação para o browser, feita só com HTML, CSS e JavaScript, que vai servir de ponto de partida a esse laboratório. Chama-se "Plano de estudo local". Tem um formulário onde escreves uma tarefa que queres praticar e escolhes a área (HTML, CSS, JavaScript ou Git), uma lista onde as tarefas aparecem depois de as adicionares e um botão para limpar a lista.

São três ficheiros, cada um com o seu papel:

- [index.html](index.html) é a página, com o formulário e a lista, que começa vazia;
- [styles.css](styles.css) trata da apresentação, e muda a disposição da página conforme a largura do ecrã;
- [app.js](app.js) é o JavaScript: recebe o envio do formulário, guarda cada tarefa numa lista e volta a mostrar essa lista na página.

Para experimentares, abre o `index.html` num browser. Não precisas de instalar nada nem de estar ligado à internet. As tarefas ficam guardadas só enquanto a página estiver aberta: se a recarregares, desaparecem. Perceber porquê faz parte do laboratório.

O laboratório completo, com os passos explicados um a um, é publicado com o bloco de formulários, depois dos guias de JavaScript no browser e de eventos, que explicam o que o `app.js` usa. Até lá, se quiseres espreitar o código, começa pelo `index.html` e depois lê os comentários do `app.js`, que dizem o que faz cada parte.
