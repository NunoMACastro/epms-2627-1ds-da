# Formulário local: material de apoio

Código de partida do laboratório do tema 08 de frontend, sobre os formulários, a validação e os ficheiros de JavaScript separados. O laboratório ainda não está publicado.

Esta pasta tem uma pequena aplicação para o browser, feita só com HTML, CSS e JavaScript. Chama-se "Plano de estudo local". Tem um formulário onde escreves uma tarefa que queres praticar e escolhes a área: HTML, CSS, JavaScript ou Git. Depois de adicionada, a tarefa aparece numa lista, e um botão limpa a lista.

São três ficheiros, cada um com o seu papel:

- [index.html](index.html): a página, com o formulário e a lista, que começa vazia;
- [styles.css](styles.css): a apresentação, que muda a arrumação da página conforme a largura do ecrã;
- [app.js](app.js): o JavaScript, que recebe o envio do formulário, guarda cada tarefa numa lista e volta a mostrar essa lista na página.

Para experimentares, abre o `index.html` num browser. Não precisas de instalar nada nem de estar ligado à internet. As tarefas ficam guardadas só enquanto a página estiver aberta: se a recarregares, desaparecem. Perceber porquê faz parte do laboratório.

O laboratório completo, com os passos explicados um a um, sai com o tema 08. Antes dele vêm os temas 06 e 07, que explicam o JavaScript no browser e os eventos que o `app.js` usa. Até lá, se quiseres espreitar o código, começa pelo `index.html`. Depois lê os comentários do `app.js`, que dizem o que faz cada parte.
