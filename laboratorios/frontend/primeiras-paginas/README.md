# Primeiras páginas: material de apoio

Material de apoio ao [laboratório de HTML e semântica](../../../01-frontend/02-html-e-semantica-laboratorio.md).

Esta pasta tem um único ficheiro, a [imagem provisória](imagem-provisoria.svg). Serve para quem, na fase 5 do laboratório, ainda não tem nenhuma imagem do tema do seu site. É um retângulo cinzento com o desenho de uma montanha e as palavras "Imagem provisória". Mede 400 píxeis de largura por 300 de altura.

Se tens o repositório da disciplina no computador, o ficheiro está nesta pasta, `laboratorios/frontend/primeiras-paginas`. Se estás a ler isto no GitHub, abre a imagem provisória. Por cima dela, ao lado do botão Raw, carrega no ícone Download raw file, que quer dizer "descarregar o ficheiro tal como está". Fica com o nome `imagem-provisoria.svg`.

Para a usares, copia-a para a pasta `imagens` do teu site e escreve no teu HTML:

```html
<img src="imagens/imagem-provisoria.svg" alt="Imagem provisória" width="400" height="300">
```

O texto alternativo diz o que a imagem mostra: neste caso, só as palavras "Imagem provisória". Quando tiveres a imagem verdadeira, troca o ficheiro, o `src`, as medidas e o `alt`, que passa a descrever a imagem nova. Uma imagem provisória não deve ficar num site publicado.
