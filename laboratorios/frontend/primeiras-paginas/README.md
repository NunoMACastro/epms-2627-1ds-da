# Primeiras páginas: material de apoio

UC02833 · bloco F02 · apoio ao [laboratório de HTML e semântica](../../../01-frontend/02-html-e-semantica-laboratorio.md).

Esta pasta tem um único ficheiro, a [imagem provisória](imagem-provisoria.svg). Serve para quem, na parte 6 do laboratório, ainda não tem nenhuma imagem do tema do seu site. É um retângulo cinzento com o desenho de uma montanha e as palavras "Imagem provisória", e mede 400 píxeis de largura por 300 de altura.

Para a usares, copia-a para a pasta `imagens` do teu site e escreve no teu HTML:

```html
<img src="imagens/imagem-provisoria.svg" alt="Imagem provisória" width="400" height="300">
```

O texto alternativo diz o que a imagem mostra, como pede o guia: neste caso, só as palavras "Imagem provisória". Quando tiveres a imagem verdadeira, troca o ficheiro, o `src`, as medidas e o `alt`, que passa a descrever a imagem nova. Uma imagem provisória não deve ficar num site publicado.
