# Projeto: o teu site

Ao longo do ano, cada aluno faz o seu próprio site, com HTML, CSS e JavaScript no browser. Escolhes o tema de um menu que o professor te dá na aula.

Os [modelos do projeto](modelos/README.md) servem para planear e documentar o site. O professor diz-te quando preenches cada um e o que entregas em cada fase.
