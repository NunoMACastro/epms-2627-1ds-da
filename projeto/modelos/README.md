# Modelos do projeto

Para usares um modelo, abre-o aqui no GitHub e carrega em Raw. Copia o texto para um ficheiro novo no VS Code e apaga a primeira e a última linha, que são as imagens da disciplina. Depois preenche os campos entre chavetas duplas.

- [Modelo do brief](brief-e-wireframe.md): o plano do teu site, com o público, o conteúdo, o mapa das páginas e os wireframes. Começa-se no tema 01, e o guia desse tema diz quando se preenche cada campo.
- [Plano do projeto](projeto-frontend.md): o problema, os limites e os passos do site até à entrega. Acompanha o site do plano à entrega, com um campo para cada marco, e o professor diz-te em que tema o começas.
- [README do site](readme-do-projeto.md): como se abre o teu site, o que tem e como o testaste. Diz também de onde vêm, e que licença têm, as imagens e os tipos de letra que não são teus.
