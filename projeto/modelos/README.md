# Modelos do projeto

Copia o modelo que o professor pedir e preenche os campos entre chavetas duplas.

- [Modelo do brief](brief-e-wireframe.md): o plano do teu site, com o público, o conteúdo, o mapa das páginas e os wireframes. Começa-se no tema 01, e o guia desse tema diz quando se preenche cada campo.
- [Plano do projeto](projeto-frontend.md): o problema, os limites e os passos do site até à entrega.
- [README do site](readme-do-projeto.md): como se abre o teu site, o que tem e como o testaste. Diz também de onde vêm as imagens e os tipos de letra que não são teus.
