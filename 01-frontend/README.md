# Frontend

O frontend é a parte de uma aplicação que corre no browser, a que o utilizador vê e usa. Nesta área constróis o teu site, do plano em papel até à publicação. Corresponde ao módulo UC02833, Conceber aplicações para a web na vertente frontend. Cada tema tem estes documentos:

- o guia, com a matéria por escrito, para estudares;
- o laboratório, para fazeres no computador, passo a passo;
- a ficha de exercícios, para treinares sozinho.
