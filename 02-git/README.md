# Git e GitHub

O Git guarda as versões do teu site, cada uma com a data, o autor e uma frase que diz o que mudou. Nesta área aprendes a guardar o histórico do teu site no teu computador e, depois, a partilhá-lo no GitHub. Corresponde ao módulo UC00617, Utilizar serviços Git e GitHub. Cada tema tem estes documentos:

- o guia, com a matéria por escrito, para estudares;
- o laboratório, para fazeres no computador, passo a passo;
- a ficha de exercícios, para treinares sozinho.
